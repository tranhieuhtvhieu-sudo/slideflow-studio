🔗 Link chia sẻ nhanh cho cả Team (Tự kết nối sẵn):
Mã Google Apps Script v3 (Chống lỗi CORS + JSONP + Báo Form tức thì)
🚀 4 Bước cài đặt Real-Time 100% Free & Xử lý lỗi kết nối:
1. Mở Google Sheets PPTX (Câu trả lời) → Tiện ích mở rộng → Apps Script → Xóa mã cũ, dán Code v3 ở trên và bấm Lưu (Ctrl+S).
2. Bấm Triển khai (Deploy) → Tùy chọn triển khai mới → Loại: Ứng dụng web: • Thực thi dưới tên: Tôi (Me)  |  Ai có quyền truy cập: Bất kỳ ai (Anyone) → Copy link có đuôi /exec (không dùng link /dev hay /edit).
3. Nếu đã từng triển khai bản cũ, bấm Triển khai → Quản lý các tùy chọn triển khai → Biểu tượng cây bút → Phiên bản: Phiên bản mới để áp dụng Code v3.
4. Vào mục Đồng hồ (Triggers) bên trái Apps Script → Thêm Trigger chạy hàm onFormSubmit khi Gửi biểu mẫu (On form submit) để nhận đơn tức thì.
